Phase 1 of the deep player enhancements (the user approved the whole plan on 2026-11-11 except kids rules and seek-bar thumbnails; tests are written but not run, at the user's request).

- **Model:** three layers. Device (`DeviceSettings`, hardware-bound: quality, deinterlace, tone mapping, audio device…), profile defaults (`ProfileSettings.picture`, `picturePresets` ≤ 8 named), per title (`store.TitleAdjustments`, bucket `profiles/<id>/titles/<content id>`, the show's id for every episode; local only, never Nuvio). Later phases add sections (framing, quality, sound) to `TitleAdjustments` and must extend `empty()` / `valid()`.
- **Go resolves at Load:** `player.pictureFor(opts)` takes `opts.Picture`, else the title's, else the profile's, through an optional `adjustments` interface type-asserted on `UseSettings`' value (`store.Service` has it; test fakes needn't). So the picker, next episode, switcher and reloads need no frontend change. Every Load sets all five props, since the session keeps the last file's.
- **Types live in `store`** and `player` uses them (`LoadOptions.Picture *store.Picture`, `SetPicture(store.Picture)`), unlike `SubtitleStyle`, which is duplicated. Keep new settings this way.
- **mpv:** brightness/contrast/saturation/gamma/hue are the VO equalizer, applied in the renderer on both macOS's render-API `gpu` renderer and Windows' `gpu-next`: no filter, zero-copy hwdec kept. ShadowLift adds 15 to gamma (cap 100).
- **Frontend:** `lib/picture.ts` (preset values, `pictureOf` = Go's rule, `withValue` turns a hand change into Custom), `lib/title-adjustments.ts` (query, `withSection`, optimistic save), `components/player/picture-sheet.tsx`, shared `panel-controls.tsx` (moved out of subtitle-panel: Field, Segmented, PanelSlider with `onCommit`/`onActive`, Stepper, RoundStep, Toggle). While a slider drags, the sheet goes transparent and only that row stays on its own pill (live preview). Settings › Playback › Picture: default preset, own presets with Delete, "Titles with their own picture" + Clear.
- **Keys:** P opens/closes the sheet (not while typing a preset name); the window handler treats it like the subtitle panel (`menuOpen`). Planned keys for later phases: W fit, Shift+A aspect, = − 0 zoom, ⌥+arrows pan, [ ] Backspace speed, , . frame step, L A–B, PageUp/Down chapters, Shift+S screenshot, Shift+I stats, Shift+C second subtitles, R/Shift+R subtitle position, B dialogue boost. The handler lowercases `event.key`, so Shift keys need their own map.
- **Plan facts for later phases (checked in the pinned sources):** render API = old `gpu` renderer (has `sharpen`, gpu-next doesn't → CAS shader for both); Apple GL 4.1 has no compute (`//!COMPUTE` shaders and `hdr-compute-peak` don't work on macOS); `cropdetect` and `eq` are GPL-only (auto-crop = sample frames with `screenshot-raw` in Go); `equalizer`/`bass`/`treble` (af_biquads.c), `dialoguenhance`, `acompressor`, `speechnorm` are LGPL; FFmpeg has no encoders, so screenshots are encoded to PNG in Go; mpv has no `secondary-sub-scale` (draw `secondary-sub-text` in the webview); the macOS layer draws on demand, so motion smoothing needs a display-link loop + `display-fps-override`.
