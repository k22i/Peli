The product is **Sinag** (SEE-nag), chosen 2026-10-19. The user wanted Filipino heritage and rejected respelling a name phonetically (e.g. "Seeneh").

**Why:** "Cove" clashed with an existing media player, and "Marquee" with a Plex-related app. A quick web search found no streaming app named Sinag. Trademark, domain and store checks are still open in #82, along with the icon and wordmark.

**How to apply:** repo is `k22i/Sinag`, bundle id `k22i.net.sinag`, keychain service `Sinag`, data at `Sinag/sinag.db`. Recorded results under `spikes/*/results` deliberately still say Cove. Brand look: [[sinag-design-direction]].
