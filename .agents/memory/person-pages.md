`/person/$id` (`routes/person.$id.tsx` → `components/title/person-page.tsx`) shows a TMDB person: photo over `Ambient` (as the folder's CoverHeader), name, known-for department, birth/death facts, biography clamped to 5 lines with Read more / Show less, then one `PosterGrid` per kind of work under one Popular/Newest chip group. `lib/tmdb-person.ts`: `parseTmdbPerson`, `sortCredits`, `useTmdbPerson(id)`; one request `/person/{id}?append_to_response=combined_credits,external_ids,images` (key `["tmdb","person",id]`, persisted, a day). `external_ids` and `images` are asked for but unused.

**Why:** B1 left names as plain `PersonLink` spans carrying the TMDB id; this makes them go somewhere.

**How to apply:**
- Groups: cast → "Acting", crew by TMDB `department` (Directing, Writing, Production, Sound…); known-for department first, then Acting/Directing/Writing/Production/Sound, rest in TMDB order. Titles are deduped per group; two jobs on one title join in `role` ("Writer, Screenplay"). Cards show "year · role". Titles open through `useOpenRelated` (exported from `related-rows.tsx`): IMDb id looked up on click, see [[title-page-tmdb]].
- `PersonLink` is a TanStack `Link` with a focus ring; `decorative` makes a second link (the cast photo) `aria-hidden` and untabbable so the name is the one stop. Used by About and CastList.
- No key: notice with a link to `/settings?section=content` (the TMDB row lives there). Unknown id: "TMDB doesn't know this person". Back button is `BackButton hero={null}` (plain glass).
- Kids profiles: bio shows, filmography doesn't (credits can't be checked against the addon allow-list, so fail closed; also hidden while the profile loads).
- Task A's shared card context menu wasn't on main, so the cards have none yet.
- Tests: `routes/person.test.tsx` raises `asyncUtilTimeout` to 5 s (the first render loads route chunks cold and missed 1 s); dates use the system locale, so match them with a regex. `routeTree.gen.ts` is regenerated by any vite/vitest run after adding a route; commit it.
- Pre-existing: `pnpm check` has ProfileSettings type errors in unrelated tests, and the full `pnpm test` fails ~55 tests elsewhere (shell "Main" nav not found, plugins, player…) on this branch.
